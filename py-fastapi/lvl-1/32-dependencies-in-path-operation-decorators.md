# Зависимости в декораторах операций пути

> Перевод страницы [Dependencies in path operation decorators](https://fastapi.tiangolo.com/tutorial/dependencies/dependencies-in-path-operation-decorators/) документации FastAPI.
> Оригинал: © Sebastián Ramírez, лицензия MIT.

В некоторых случаях возвращаемое значение зависимости внутри *функции операции пути* на самом деле не нужно.

Или зависимость вообще не возвращает значения.

Но её всё равно нужно выполнить/разрешить.

Для таких случаев вместо объявления параметра *функции операции пути* с `Depends` можно добавить список (`list`) `dependencies` в *декоратор операции пути*.

## Добавьте `dependencies` в *декоратор операции пути*

*Декоратор операции пути* принимает необязательный аргумент `dependencies`.

Это должен быть `list` из `Depends()`:

```python title="dependencies/tutorial006_an_py310.py"
from typing import Annotated

from fastapi import Depends, FastAPI, Header, HTTPException

app = FastAPI()


async def verify_token(x_token: Annotated[str, Header()]):
    if x_token != "fake-super-secret-token":
        raise HTTPException(status_code=400, detail="X-Token header invalid")


async def verify_key(x_key: Annotated[str, Header()]):
    if x_key != "fake-super-secret-key":
        raise HTTPException(status_code=400, detail="X-Key header invalid")
    return x_key


@app.get("/items/", dependencies=[Depends(verify_token), Depends(verify_key)])
async def read_items():
    return [{"item": "Foo"}, {"item": "Bar"}]
```

Эти зависимости будут выполнены/разрешены так же, как обычные зависимости. Но их значение (если они что-то возвращают) не будет передано в вашу *функцию операции пути*.

> **Совет**
>
> Некоторые редакторы проверяют неиспользуемые параметры функций и показывают их как ошибки.
>
> Используя такие `dependencies` в *декораторе операции пути*, можно гарантировать их выполнение и при этом избежать ошибок редактора/инструментов.
>
> Это также может уберечь от путаницы новых разработчиков, которые увидят в коде неиспользуемый параметр и могут решить, что он не нужен.

> **Примечание**
>
> В этом примере мы используем придуманные собственные заголовки `X-Key` и `X-Token`.
>
> Но в реальных случаях при реализации безопасности больше пользы принесёт использование встроенных [утилит безопасности (следующая глава)](35-security.md).

## Ошибки зависимостей и возвращаемые значения

Можно использовать те же *функции* зависимостей, что и обычно.

### Требования зависимостей

Они могут объявлять требования к запросу (например, заголовки) или другие подзависимости — как `x_token: Annotated[str, Header()]` в примере выше.

### Возбуждение исключений

Эти зависимости могут возбуждать (`raise`) исключения так же, как обычные зависимости — как `raise HTTPException(...)` в примере выше.

### Возвращаемые значения

Они могут возвращать значения или нет — значения использоваться не будут.

Так что можно переиспользовать обычную зависимость (которая возвращает значение), уже используемую где-то ещё, и хотя значение не будет использовано, зависимость будет выполнена — как `verify_key`, которая возвращает `x_key`.
