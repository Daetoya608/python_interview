# Код статуса ответа

> Перевод страницы [Response Status Code](https://fastapi.tiangolo.com/tutorial/response-status-code/) документации FastAPI.
> Оригинал: © Sebastián Ramírez, лицензия MIT.

Так же как можно указать модель ответа, можно объявить и HTTP-код статуса ответа с помощью параметра `status_code` в любой *операции пути*:

* `@app.get()`
* `@app.post()`
* `@app.put()`
* `@app.delete()`
* и т. д.

```python title="response_status_code/tutorial001_py310.py"
from fastapi import FastAPI

app = FastAPI()


@app.post("/items/", status_code=201)
async def create_item(name: str):
    return {"name": name}
```

> **Примечание**
>
> Обратите внимание, что `status_code` — это параметр метода «декоратора» (`get`, `post` и т. д.), а не вашей *функции операции пути*, как все параметры и тело.

Параметр `status_code` принимает число — HTTP-код статуса.

> **Примечание**
>
> `status_code` может также принимать `IntEnum`, например [`http.HTTPStatus`](https://docs.python.org/3/library/http.html#http.HTTPStatus) из Python.

Он:

* Вернёт этот код статуса в ответе.
* Задокументирует его соответствующим образом в схеме OpenAPI (а значит, и в пользовательских интерфейсах):

<img src="https://fastapi.tiangolo.com/img/tutorial/response-status-code/image01.png">

> **Примечание**
>
> Некоторые коды ответа (см. следующий раздел) означают, что у ответа нет тела.
>
> FastAPI это знает и сгенерирует документацию OpenAPI, в которой указано, что тела ответа нет.

## О HTTP-кодах статуса

> **Примечание**
>
> Если вы уже знаете, что такое HTTP-коды статуса, переходите к следующему разделу.

В HTTP в составе ответа отправляется числовой код статуса из 3 цифр.

У этих кодов есть связанное с ними название, помогающее их распознавать, но важна именно цифра.

Коротко:

* `100 - 199` — «Информационные». Напрямую их используют редко. Ответы с этими кодами не могут иметь тела.
* **`200 - 299`** — «Успешные» ответы. Их вы будете использовать чаще всего.
    * `200` — код статуса по умолчанию, означающий, что всё «OK».
    * Другой пример — `201`, «Created» (создано). Обычно используется после создания новой записи в базе данных.
    * Особый случай — `204`, «No Content» (нет содержимого). Этот ответ используется, когда клиенту нечего возвращать, поэтому у ответа не должно быть тела.
* **`300 - 399`** — «Перенаправление». Ответы с этими кодами могут иметь или не иметь тело, кроме `304`, «Not Modified» (не изменено), у которого тела быть не должно.
* **`400 - 499`** — ответы «Ошибка клиента». Это, вероятно, второй по частоте использования тип.
    * Пример — `404`, ответ «Not Found» (не найдено).
    * Для общих ошибок клиента можно просто использовать `400`.
* `500 - 599` — ошибки сервера. Напрямую их почти никогда не используют. Когда что-то идёт не так в какой-то части кода приложения или на сервере, автоматически возвращается один из этих кодов.

> **Совет**
>
> Чтобы узнать больше о каждом коде статуса и о том, какой код для чего, загляните в [документацию <abbr title="Mozilla Developer Network">MDN</abbr> о HTTP-кодах статуса](https://developer.mozilla.org/en-US/docs/Web/HTTP/Status).

## Способ не запоминать названия

Снова посмотрим на предыдущий пример:

```python title="response_status_code/tutorial001_py310.py"
@app.post("/items/", status_code=201)
async def create_item(name: str):
    return {"name": name}
```

`201` — это код статуса «Created».

Но запоминать, что означает каждый из этих кодов, не нужно.

Можно использовать удобные переменные из `fastapi.status`.

```python title="response_status_code/tutorial002_py310.py"
from fastapi import FastAPI, status

app = FastAPI()


@app.post("/items/", status_code=status.HTTP_201_CREATED)
async def create_item(name: str):
    return {"name": name}
```

Это просто для удобства — в них то же самое число, но так их можно находить с помощью автодополнения в редакторе:

<img src="https://fastapi.tiangolo.com/img/tutorial/response-status-code/image02.png">

> **Примечание | Технические подробности**
>
> Можно также использовать `from starlette import status`.
>
> **FastAPI** предоставляет тот же `starlette.status` в виде `fastapi.status` просто для удобства разработчика. Но он берётся напрямую из Starlette.
