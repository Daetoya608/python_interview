# Статические файлы

> Перевод страницы [Static Files](https://fastapi.tiangolo.com/tutorial/static-files/) документации FastAPI.
> Оригинал: © Sebastián Ramírez, лицензия MIT.

С помощью `StaticFiles` можно автоматически отдавать статические файлы из директории.

> **Совет**
>
> Если нужно разместить фронтенд, используйте вместо этого `app.frontend()` — о нём читайте в разделе [Фронтенд](48-frontend.md).
>
> `app.frontend()` «под капотом» использует `StaticFiles`, но с несколькими дополнительными преимуществами для фронтендов, например с обработкой маршрутизации на стороне клиента.

## Используйте `StaticFiles`

* Импортируйте `StaticFiles`.
* «Смонтируйте» (mount) экземпляр `StaticFiles()` по определённому пути.

```python title="static_files/tutorial001_py310.py"
from fastapi import FastAPI
from fastapi.staticfiles import StaticFiles

app = FastAPI()

app.mount("/static", StaticFiles(directory="static"), name="static")
```

> **Примечание | Технические подробности**
>
> Можно также использовать `from starlette.staticfiles import StaticFiles`.
>
> **FastAPI** предоставляет тот же `starlette.staticfiles` в виде `fastapi.staticfiles` просто для удобства разработчика. Но на самом деле он берётся напрямую из Starlette.

### Что такое «монтирование»

«Монтирование» означает добавление полноценного «независимого» приложения по определённому пути, которое затем обрабатывает все подпути.

Это отличается от использования `APIRouter`, поскольку смонтированное приложение полностью независимо. OpenAPI и документация основного приложения не будут включать ничего из смонтированного приложения и т. д.

Подробнее об этом можно прочитать в [Продвинутом руководстве пользователя](https://fastapi.tiangolo.com/advanced/).

## Подробности

Первый аргумент `"/static"` — это подпуть, по которому будет «смонтировано» это «подприложение». Так что любой путь, начинающийся с `"/static"`, будет обрабатываться им.

`directory="static"` — имя директории, содержащей ваши статические файлы.

`name="static"` даёт ему имя, которое может использоваться внутри **FastAPI**.

Все эти параметры могут отличаться от «`static`» — настройте их под нужды и особенности своего приложения.
