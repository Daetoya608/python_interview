# Безопасность — первые шаги

> Перевод страницы [Security - First Steps](https://fastapi.tiangolo.com/tutorial/security/first-steps/) документации FastAPI.
> Оригинал: © Sebastián Ramírez, лицензия MIT.

Представим, что у вас есть **бэкенд**-API на каком-то домене.

А **фронтенд** — на другом домене или по другому пути того же домена (или в мобильном приложении).

И вам нужен способ, чтобы фронтенд мог аутентифицироваться в бэкенде с помощью **имени пользователя** и **пароля**.

Для этого с **FastAPI** можно использовать **OAuth2**.

Но давайте сэкономим вам время на чтение всей длинной спецификации ради нескольких нужных кусочков информации.

Воспользуемся инструментами, которые **FastAPI** предоставляет для работы с безопасностью.

## Как это выглядит

Сначала просто воспользуемся кодом и посмотрим, как он работает, а потом вернёмся и разберёмся, что происходит.

## Создайте `main.py`

Скопируйте пример в файл `main.py`:

```python title="security/tutorial001_an_py310.py"
from typing import Annotated

from fastapi import Depends, FastAPI
from fastapi.security import OAuth2PasswordBearer

app = FastAPI()

oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")


@app.get("/items/")
async def read_items(token: Annotated[str, Depends(oauth2_scheme)]):
    return {"token": token}
```

## Поток `password`

Теперь вернёмся немного назад и разберёмся, что всё это значит.

«Поток» (flow) `password` — один из способов («потоков»), определённых в OAuth2 для обеспечения безопасности и аутентификации.

OAuth2 был спроектирован так, чтобы бэкенд или API могли быть независимы от сервера, который аутентифицирует пользователя.

Но в данном случае одно и то же приложение **FastAPI** будет обслуживать и API, и аутентификацию.

Поэтому рассмотрим это с такой упрощённой точки зрения:

* Пользователь вводит `username` и `password` во фронтенде и нажимает `Enter`.
* Фронтенд (работающий в браузере пользователя) отправляет эти `username` и `password` на определённый URL нашего API (объявленный с помощью `tokenUrl="token"`).
* API проверяет `username` и `password` и отвечает «токеном» (ничего из этого мы пока не реализовали).
    * «Токен» — это просто строка с некоторым содержимым, которое мы можем позже использовать, чтобы проверить этого пользователя.
    * Обычно токен настраивается так, чтобы истекать через какое-то время.
        * Так что пользователю придётся в какой-то момент снова войти в систему.
        * А если токен украдут, риск меньше. Это не постоянный ключ, который будет работать вечно (в большинстве случаев).
* Фронтенд где-то временно сохраняет этот токен.
* Пользователь щёлкает во фронтенде, чтобы перейти в другой раздел веб-приложения.
* Фронтенду нужно получить ещё данные из API.
    * Но для этого конкретного эндпоинта нужна аутентификация.
    * Поэтому, чтобы аутентифицироваться в нашем API, он отправляет заголовок `Authorization` со значением `Bearer ` плюс токен.
    * Если токен содержит `foobar`, содержимое заголовка `Authorization` будет таким: `Bearer foobar`.

## `OAuth2PasswordBearer` в **FastAPI**

**FastAPI** предоставляет несколько инструментов на разных уровнях абстракции для реализации этих функций безопасности.

В этом примере мы будем использовать **OAuth2** с потоком **Password** и токеном **Bearer**. Для этого используется класс `OAuth2PasswordBearer`.

> **Примечание**
>
> Токен «bearer» — не единственный вариант.
>
> Но для нашего случая он лучший.
>
> И, возможно, лучший для большинства случаев, если только вы не эксперт по OAuth2 и точно знаете, почему другой вариант лучше подходит для ваших нужд.
>
> В таком случае **FastAPI** тоже даёт вам инструменты, чтобы его построить.

При создании экземпляра класса `OAuth2PasswordBearer` мы передаём параметр `tokenUrl`. Этот параметр содержит URL, который клиент (фронтенд, работающий в браузере пользователя) будет использовать, чтобы отправить `username` и `password` и получить токен.

```python title="security/tutorial001_an_py310.py"
oauth2_scheme = OAuth2PasswordBearer(tokenUrl="token")
```

> **Совет**
>
> Здесь `tokenUrl="token"` указывает на относительный URL `token`, который мы ещё не создали. Поскольку это относительный URL, он эквивалентен `./token`.
>
> Поскольку мы используем относительный URL, если бы ваш API находился по адресу `https://example.com/`, он указывал бы на `https://example.com/token`. А если бы ваш API находился по адресу `https://example.com/api/v1/`, он указывал бы на `https://example.com/api/v1/token`.
>
> Использование относительного URL важно, чтобы приложение продолжало работать даже в продвинутых сценариях вроде [работы за прокси](https://fastapi.tiangolo.com/advanced/behind-a-proxy/).

Этот параметр не создаёт этот эндпоинт / *операцию пути*, а объявляет, что URL `/token` — это тот, который клиент должен использовать для получения токена. Эта информация используется в OpenAPI, а затем в системах интерактивной документации API.

Скоро мы создадим и саму операцию пути.

> **Примечание**
>
> Если вы очень строгий «питонист», вам может не понравиться стиль имени параметра `tokenUrl` вместо `token_url`.
>
> Дело в том, что используется то же имя, что и в спецификации OpenAPI. Чтобы, если понадобится подробнее изучить какую-либо из этих схем безопасности, можно было просто скопировать имя и найти о нём информацию.

Переменная `oauth2_scheme` — экземпляр `OAuth2PasswordBearer`, но при этом она также «вызываемый объект».

Её можно вызвать так:

```Python
oauth2_scheme(some, parameters)
```

Поэтому её можно использовать с `Depends`.

### Используйте её

Теперь эту `oauth2_scheme` можно передать в зависимость через `Depends`.

```python title="security/tutorial001_an_py310.py"
@app.get("/items/")
async def read_items(token: Annotated[str, Depends(oauth2_scheme)]):
    return {"token": token}
```

Эта зависимость предоставит `str`, который присваивается параметру `token` *функции операции пути*.

**FastAPI** будет знать, что эту зависимость можно использовать для определения «схемы безопасности» в схеме OpenAPI (и в автоматической документации API).

> **Примечание | Технические подробности**
>
> **FastAPI** будет знать, что класс `OAuth2PasswordBearer` (объявленный в зависимости) можно использовать для определения схемы безопасности в OpenAPI, потому что он наследуется от `fastapi.security.oauth2.OAuth2`, который, в свою очередь, наследуется от `fastapi.security.base.SecurityBase`.
>
> Все утилиты безопасности, интегрирующиеся с OpenAPI (и автоматической документацией API), наследуются от `SecurityBase` — так **FastAPI** узнаёт, как интегрировать их в OpenAPI.

## Что он делает

Он ищет в запросе заголовок `Authorization`, проверяет, что значение — это `Bearer ` плюс какой-то токен, и возвращает токен как `str`.

Если он не видит заголовка `Authorization` или в значении нет токена `Bearer `, он сразу ответит ошибкой с кодом статуса 401 (`UNAUTHORIZED`).

Вам даже не нужно проверять, существует ли токен, чтобы вернуть ошибку. Можно быть уверенным, что если ваша функция выполняется, в этом токене будет `str`.
