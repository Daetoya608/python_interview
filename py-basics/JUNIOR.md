# Основы Python — Junior

## Объекты, ссылки и изменяемость

Переменная — имя, связанное с объектом. Присваивание не копирует объект; аргумент функции также связывается с переданным объектом. `==` сравнивает значения, `is` — идентичность. Для None обычно пишут `value is None`.

Неизменяемые встроенные типы: int, float, bool, str, tuple, frozenset. Изменяемые: list, dict, set. Изменение объекта видно через все ссылки на него; перепривязка одного имени не меняет остальные.

```python
import copy

a = [[1]]
b = a                 # Тот же объект.
c = a.copy()          # Новый внешний список, вложенный общий.
d = copy.deepcopy(a)  # Независимая копия вложенной структуры.
a[0].append(2)
assert b == c == [[1, 2]]
assert d == [[1]]
a = []                # b продолжает ссылаться на старый список.
```

Tuple нельзя изменить по составу ссылок, но он может содержать изменяемый список: `items = ([1],); items[0].append(2)` допустимо.

## Коллекции и hashability

| Тип | Когда применять |
|---|---|
| list | Упорядоченная изменяемая последовательность; допускает дубли |
| tuple | Последовательность с фиксированным составом, например пара координат |
| dict | Поиск значения по ключу; сохраняет порядок вставки |
| set | Уникальные элементы, проверка принадлежности, операции множеств; порядок не гарантирован |

Ключ dict и элемент set должны быть **hashable**: иметь стабильный в течение жизни hash и согласованное равенство. Если `a == b`, их hashes должны совпадать; совпавший hash не доказывает равенства. List/dict/set не hashable. Tuple hashable, только если hashable все его элементы. Неизменяемость сама по себе не универсальное определение hashability.

Базовый синтаксис:

```python
prices = {"book": 100, "pen": 20}
selected = [name for name, price in prices.items() if price >= 50]
assert selected == ["book"]
for number in range(3):  # 0, 1, 2; правая граница не входит.
    if number == 1:
        continue
```

Отступы задают блоки. `if/elif/else` выбирают ветку, `for` перебирает iterable, `while` повторяет по условию. `break` завершает цикл, `continue` переходит к следующей итерации. None, False, числовой ноль и пустые стандартные коллекции ложны в условии. Проверка `if value:` не равна `if value is not None:`.

## Функции, defaults и области видимости

Функция — объект: её можно присвоить имени, передать аргументом и вернуть. `return` завершает вызов; без явного результата возвращается None. `*args` собирает позиционные аргументы в tuple, `**kwargs` — именованные в dict. `*items`/`**mapping` в вызове распаковывают аргументы.

Default вычисляется **при определении функции**, а не при каждом вызове. Поэтому изменяемый default может неожиданно разделяться между вызовами:

```python
def add_item(item, items=None):
    if items is None:
        items = []
    items.append(item)
    return items

assert add_item(1) == [1]
assert add_item(2) == [2]
```

Поиск имён — **LEGB**: Local → Enclosing (внешние функции) → Global (модуль) → Builtins. Присваивание внутри функции обычно делает имя локальным. `global` перепривязывает имя модуля, `nonlocal` — существующее имя внешней функции. Изменять переданный список можно без global: это изменение объекта, а не перепривязка имени.

Чтение локального имени до присваивания может вызвать UnboundLocalError, даже если одноимённая глобальная переменная существует.

## Исключения

`raise` сигнализирует об ошибке; `except` обрабатывает выбранный тип и его подклассы. `else` выполняется, если try завершился без исключения; `finally` — при выходе из блока, в том числе при ошибке/return. Не ловите все ошибки молча: можно скрыть дефект программы.

```python
def parse_positive(text):
    try:
        value = int(text)
    except ValueError as error:
        raise ValueError("expected an integer") from error
    if value <= 0:
        raise ValueError("expected a positive number")
    return value
```

## Iterable, iterator, generator

**Iterable** — объект для перебора, из которого получают iterator через iter. **Iterator** хранит позицию, выдаёт следующий элемент через next и завершает перебор исключением StopIteration. Итератор обычно потребляется однократно; список позволяет создавать новые итераторы.

Функция с `yield` создаёт **генератор**, разновидность итератора. Тело запускается при продвижении, сохраняет состояние между yield и не материализует все результаты сразу. `return` завершает генератор.

```python
def squares(limit):
    for number in range(limit):
        yield number * number

values = squares(3)
assert next(values) == 0
assert list(values) == [1, 4]
assert list(values) == []  # Уже исчерпан.
```

## Декораторы и контекстные менеджеры

Декоратор получает функцию и возвращает объект, который займёт её имя. `@decorate` над f примерно означает `f = decorate(f)`. Обёртка может добавить проверку/логирование, сохранив вызов исходной функции. `wraps` сохраняет её метаданные.

```python
from functools import wraps

def logged(function):
    @wraps(function)
    def wrapper(*args, **kwargs):
        print("Calling", function.__name__)
        return function(*args, **kwargs)
    return wrapper

@logged
def double(number):
    return number * 2

assert double(3) == 6
```

`with` управляет входом/выходом из контекста через `__enter__`/`__exit__`. Нужен, чтобы освобождать ресурс и при исключении. Возврат истинного значения из `__exit__` может подавить исключение; обычное закрытие файла его не подавляет.

```python
from io import StringIO

with StringIO("hello") as stream:
    assert stream.read() == "hello"
assert stream.closed
```

## Основы ООП

Класс описывает тип, экземпляр — конкретный объект со своим состоянием. `self` — экземпляр в методе; `__init__` инициализирует уже созданный объект. Атрибут экземпляра принадлежит ему, атрибут класса может разделяться всеми экземплярами: общий изменяемый список в классе часто становится ошибкой.

Инкапсуляция удерживает правила за интерфейсом, абстракция выделяет контракт, наследование создаёт подтип, полиморфизм позволяет разным объектам выполнять общий контракт. `_name` — соглашение о внутренней детали, не запрет доступа.

```python
class Counter:
    def __init__(self):
        self.value = 0

    def increment(self):
        self.value += 1

first, second = Counter(), Counter()
first.increment()
assert first.value == 1 and second.value == 0
```

При наследовании потомок может переопределить метод, а `super()` вызывает следующую реализацию по порядку разрешения методов. Если нужно только использовать поведение другого объекта, часто достаточно композиции — сохранить его в атрибуте.
