# Индексы — уровень 1

Требование [issue №5](https://github.com/Daetoya608/python_interview/issues/5): понимать, зачем нужны индексы.

## Что такое индекс

Индекс — дополнительная структура доступа, которая помогает находить строки по ключу без полного перебора таблицы. Он хранит ключи и сведения, позволяющие найти соответствующие данные; конкретное устройство зависит от движка и типа индекса.

Аналогия — предметный указатель книги: сначала ищем термин в указателе, затем открываем нужные страницы. Для чтения почти всей книги указатель может не помочь.

```sql
CREATE INDEX idx_orders_customer ON orders(customer_id);
SELECT id, amount_cents FROM orders WHERE customer_id = 42;
```

Без подходящего индекса СУБД может проверить каждую строку. С индексом она может найти диапазон ключей customer_id=42, затем получить нужные строки. **Наличие индекса не обязывает оптимизатор его использовать.**

## Какие задачи решает

- Поиск по равенству и диапазону — при подходящем типе индекса и предикате.
- Быстрый поиск внутренней стороны JOIN по ключу.
- Некоторые ORDER BY и запросы с LIMIT без отдельной полной сортировки.
- Реализация уникальности через уникальный индекс/ограничение, в зависимости от СУБД.

```sql
CREATE UNIQUE INDEX idx_customers_email ON customers(email);
```

Обычный индекс не запрещает дубликаты. Уникальный ограничивает их согласно правилам СУБД, включая особенности NULL. Индекс сам по себе не задаёт порядок ответа SELECT: нужен ORDER BY.

## Почему не индексируют всё

Индекс занимает место и должен поддерживаться при изменениях данных. Для маленькой таблицы или выборки большей части строк последовательное чтение может оказаться дешевле. На выбор влияют статистика, объём, расположение данных и стоимость доступа.

Рабочий подход: найти важный медленный запрос → посмотреть план → подобрать индекс под предикат/сортировку → проверить результат и цену записи.

## Практика

`python db-indices/practice/demo.py` создаёт SQLite в памяти, сравнивает план одного запроса до и после покрывающего индекса и проверяет равенство результатов. Не обещает универсального ускорения в N раз.
