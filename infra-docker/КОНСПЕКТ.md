# Docker: быстро повторить

- Image — шаблон; container — запущенный экземпляр + writable layer; registry — хранилище образов.
- Linux-контейнер разделяет ядро хоста: namespaces изолируют, cgroups ограничивают ресурсы. VM имеет гостевое ядро.
- `pull` скачать, `build` собрать, `run` создать/запустить, `push` опубликовать. `start` запускает существующий контейнер.
- Dockerfile: FROM, WORKDIR, COPY, RUN (сборка), ENV, USER, EXPOSE, ENTRYPOINT/CMD (запуск).
- `EXPOSE` не публикует порт. `-p 127.0.0.1:8000:8000` связывает порт хоста и контейнера; сервер внутри слушает `0.0.0.0`.
- `logs` — stdout/stderr, `exec` — процесс в работающем контейнере, `inspect` — конфигурация, `stats` — ресурсы.
- Writable layer пропадает при удалении контейнера. Volume сохраняется отдельно; bind mount — путь хоста. Оба требуют продуманного backup.
- `--memory`, `--cpus` — лимиты. Без лимитов контейнер может конкурировать за ресурсы всего хоста.
- Слои переиспользуются, кэш зависит от входов. Dependencies копируют раньше кода; multi-stage сокращает финальный состав.
- Не копировать секреты в образ: удаление в следующем слое не стирает предыдущий. Tag изменяем, digest фиксирует содержимое.
- Compose описывает services, ports, volumes, networks. `up`, `ps`, `logs`, `exec`, `down`; `down -v` удаляет данные volumes.
