# Типизация Python — Junior

## Что проверяется

Python динамически типизирован: тип имеет объект, а имя может связываться с разными объектами. Статический анализатор, например mypy, проверяет совместимость типов **до запуска**, не исполняя программу.

Аннотации документируют контракт и помогают находить ошибки. Сами по себе они не преобразуют аргументы и не запрещают вызов с неправильным runtime-типом. Внешние данные проверяют отдельно.

```python
name: str = "Anna"
scores: list[int] = [1, 2]
ages: dict[str, int] = {"Anna": 24}

def double(number: int) -> int:
    return number * 2

def show(message: str) -> None:
    print(message)
```

`: T` — тип переменной/параметра, `-> T` — результата. Если функция не возвращает значение, используют `-> None`. Аннотация без присваивания не создаёт готовое значение переменной.

## Optional и narrowing

`Optional[T]` означает `T | None`; оператор объединения доступен с Python 3.10. Это не обещание, что аргумент можно пропустить: пропуск разрешает default.

| Параметр | Пропустить аргумент | Передать None по контракту |
|---|---|---|
| name: str | Нет | Нет |
| name: str \| None | Нет | Да |
| name: str \| None = None | Да | Да |
| name: str = "Guest" | Да | Нет |

**Type narrowing** — сужение набора возможных типов после проверки:

```python
def display_name(name: str | None = None) -> str:
    if name is None:
        return "Guest"
    return name.upper()  # Здесь анализатор знает: name — str.
```

`if name:` исключает также пустую строку, поэтому имеет другой смысл. `isinstance(value, int)` помогает сузить объединение типов. `isinstance(value, list[int])` не проверяет элементы, а вызывает TypeError; `isinstance(value, list)` проверит только сам контейнер.

## Mypy

Сохрани типизированный код в `example.py`:

```console
python -m pip install mypy
python -m mypy example.py
python -m mypy --strict example.py
```

Диагностика содержит файл, строку и причину. Например `double("3")` нарушает тип аргумента (`arg-type`); возврат строки из функции `-> int` — `return-value`; присваивание строки переменной int — `assignment`.

Исправляют контракт/код или сужают тип проверкой, а не автоматически добавляют ignore. `Any` ослабляет проверку; `# type: ignore` подавляет сообщение, не исправляя проблему. Нетипизированные функции по умолчанию проверяются ограниченно; strict помогает найти пропущенные аннотации.

Зелёный mypy не доказывает правильность алгоритма: функция может вернуть неправильное число правильного типа. Нужны тесты и проверки бизнес-правил.
